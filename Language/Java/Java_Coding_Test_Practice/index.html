    풀이 코드 실행 방법¶

    각 문제지에는 구현할 메서드와 예시용 main이 있다. 문제지를 펼치면 코드 오른쪽 위에 나타나는 복사 버튼으로 전체 코드를 복사하고, IDE에서 클래스 이름과 같은 Java 파일에 붙여 넣는다. 예를 들어 01번 문제지는 Exercise01.java에 붙여 넣는다.

    TODO 주석이 있는 메서드의 throw new UnsupportedOperationException(...) 줄을 지우고 자신의 구현으로 채운다. 구현 전에 실행하면 이 예외가 발생한다. 구현 후 main을 실행하고 주석의 기대 출력과 비교한다. 필요한 import나 보조 메서드는 추가해도 된다.

    터미널에서는 다음과 같이 실행한다.

    javac -encoding UTF-8 Exercise01.java
java Exercise01

    문제지와 정답 코드는 Java 8 문법과 표준 라이브러리를 사용한다. 입력은 각 main의 배열·문자열을 바꿔 확인할 수 있으며, 표준 입력을 읽는 코드는 포함하지 않는다. 함수는 문제에 명시한 유효 입력을 받는다고 가정한다.

    1일차 큰 정수와 문자열과 스택¶

    01. 정산 조정액 합계¶

    연습 주제: 큰 정수의 합계, int와 long의 범위.

    문제¶

    정산 시스템은 금액이 늘어나면 양수, 줄어들면 음수인 조정액을 기록한다. 하루 동안 기록한 조정액을 모두 더해 최종 변동 금액을 구하라. 각각의 조정액과 전체 합계는 int 범위를 넘을 수 있다.

    제약과 함수 계약¶

    • 0 ≤ adjustments.length ≤ 100,000
    • 각 조정액은 -1,000,000,000,000 이상 1,000,000,000,000 이하이다.
    • 입력 배열은 null이 아니다. 입력 배열을 수정하지 않는다.
    • public static long total(long[] adjustments)를 구현한다.
    • 반환값은 모든 조정액의 합이다. 기록이 없으면 0을 반환한다.

    예시 1¶

    항목 값
    입력 [2400000000, 1700000000, -600000000]
    반환값 3500000000

    양수와 음수를 그대로 더한다. 결과가 int의 최댓값을 넘으므로 합계 변수도 long이어야 한다.

    항목 값
    입력 []
    반환값 0
    문제지 펼치기 · IDE에 복사

    파일명: Exercise01.java

    public static long total(long[] adjustments) {
        // TODO: 문제 조건에 맞게 구현해주세요.

    03. 설정 문자열의 괄호 검사¶

    연습 주제: 스택, 괄호의 중첩 순서.

    문제¶

    간소화된 설정 문자열에는 (, ), [, ], {, }만 들어 있다. 모든 여는 괄호가 같은 종류의 닫는 괄호와 올바른 순서로 짝지어지면 true를 반환하라. 아직 닫히지 않은 괄호 중 가장 최근에 열린 괄호부터 닫혀야 한다. 빈 문자열은 올바른 문자열로 취급한다.

    public class Exercise03 {
    public static boolean isBalanced(String text) {
        char[] stack = new char[text.length()];
        int size = 0;

        for (int i = 0; i < text.length(); i++) {
            char current = text.charAt(i);
            if (current == '(' || current == '[' || current == '{') {
                stack[size++] = current;
                continue;
            }

            if (size == 0) {
                return false;
            }
            char expected;
            if (current == ')') {
                expected = '(';
            } else if (current == ']') {
                expected = '[';
            } else {
                expected = '{';
            }
            if (stack[--size] != expected) {
                return false;
            }
        }
        return size == 0;
    }

    public static void main(String[] args) {
        System.out.println(isBalanced("{[()()]()}"));
        System.out.println(isBalanced("[({)]}"));
    }
}

    04. 장비 알림의 발생 횟수 조회¶

    연습 주제: 해시 맵 두 개로 값의 빈도와 빈도의 개수를 함께 관리하기.

    문제¶

    장비 알림 번호를 중복 저장할 수 있는 기록함이 처음에는 비어 있다. 다음 연산들을 주어진 순서대로 처리하라.

    연산 의미
    [1, x] 알림 번호 x를 한 번 추가한다.
    [2, x] 알림 번호 x를 한 번 제거한다. 없으면 아무것도 하지 않는다.
    [3, f] 현재 정확히 f번 기록된 알림 번호가 하나라도 있는지 조회한다.

    조회 연산의 결과만 모아 순서대로 반환한다. 서로 다른 번호 여러 개의 발생 횟수를 합쳐서 판단하지 않는다. 기록함에 없는 번호는 조회 대상이 아니다.

    제약과 함수 계약¶

    • 연산 수는 0 이상 200,000 이하이다.
    • 각 연산은 길이가 2인 배열이며, 첫 번째 값은 1, 2, 3 중 하나이다.
    • 알림 번호 x는 1 이상 1,000,000,000 이하의 정수이다. 조회 빈도 f는 1 이상 200,000 이하의 정수이다.
    • 입력 배열과 각 연산은 null이 아니다. 입력 배열을 수정하지 않는다.
    • public static List<Integer> processQueries(int[][] operations)를 구현한다.
    • 반환 리스트에는 [3, f] 연산의 결과만 담는다. 조건을 만족하는 번호가 있으면 1, 없으면 0을 담는다. 조회 연산이 없으면 빈 리스트를 반환한다.

    예시 1¶

    항목 값
    입력 [[1, 7], [1, 7], [1, 9], [3, 2], [2, 7], [3, 2], [3, 1]]
    반환값 [1, 0, 1]

    첫 조회에서 7은 두 번 기록되어 있다. 7을 한 번 제거하면 7과 9가 각각 한 번씩 기록되어 있으므로, 두 번 기록된 번호는 없고 한 번 기록된 번호는 있다.

    항목 값

    import java.util.ArrayList;
import java.util.HashMap;
import java.util.List;
import java.util.Map;

public class Exercise04 {
    public static List<Integer> processQueries(int[][] operations) {
        Map<Integer, Integer> counts = new HashMap<>();
        Map<Integer, Integer> population = new HashMap<>();
        List<Integer> answers = new ArrayList<>();

        for (int[] operation : operations) {
            int type = operation[0];
            int argument = operation[1];

            if (type == 3) {
                answers.add(population.getOrDefault(argument, 0) > 0 ? 1 : 0);
                continue;
            }

            int oldCount = counts.getOrDefault(argument, 0);
            if (type == 2 && oldCount == 0) {
                continue;
            }

            int newCount = type == 1 ? oldCount + 1 : oldCount - 1;
            changePopulation(population, oldCount, -1);
            if (newCount == 0) {
                counts.remove(argument);
            } else {
                counts.put(argument, newCount);
                changePopulation(population, newCount, 1);
            }
        }
        return answers;
    }

    private static void changePopulation(
            Map<Integer, Integer> population, int frequency, int delta) {
        if (frequency == 0) {
            return;
        }
        int newPopulation = population.getOrDefault(frequency, 0) + delta;
        if (newPopulation == 0) {
            population.remove(frequency);
        } else {
            population.put(frequency, newPopulation);
        }
    }

    public static void main(String[] args) {
        System.out.println(processQueries(new int[][] {
            {1, 7}, {1, 7}, {1, 9}, {3, 2},
            {2, 7}, {3, 2}, {3, 1}
        }));
        System.out.println(processQueries(new int[][] {
            {2, 4}, {3, 1}, {1, 4}, {2, 4}, {3, 1}
        }));
    }

    현재 가격이 남은 예산보다 크다면 이후 가격도 모두 더 크거나 같으므로 탐색을 끝낼 수 있다. 원본 배열을 보존하기 위해 복사본을 정렬한다. 가격과 남은 예산은 long으로 계산한다.

    완전한 Java 코드

    import java.util.Arrays;

public class Exercise05 {
    public static int maxItems(long[] prices, long budget) {
        long[] sorted = Arrays.copyOf(prices, prices.length);
        Arrays.sort(sorted);

        long remaining = budget;
        int count = 0;

        for (long price : sorted) {
            if (price > remaining) {
                break;
            }
            remaining -= price;
            count++;
        }

        return count;
    }

    public static void main(String[] args) {
        System.out.println(maxItems(new long[] {27, 13, 45, 13, 8}, 50));
        System.out.println(maxItems(new long[] {5, 12}, 0));
    }
}

    06. 일정 간격으로 떨어진 측정값 찾기¶

    문제¶

    가상의 센서에서 얻은 정수 측정값 목록이 있다. 목록의 측정값은 모두 서로 다르다. 이 중 두 값을 골랐을 때, 큰 값에서 작은 값을 뺀 차이가 정확히 k가 되는 값 쌍의 개수를 구하라.

    두 값의 순서만 바뀐 경우는 같은 쌍이다. 예를 들어 (3, 9)와 (9, 3)은 한 쌍으로 센다. 하나의 값이 여러 쌍에 포함되는 것은 허용한다.

    제약과 함수 계약¶

    • 배열은 null이 아니며, 모든 원소가 서로 다르다.

    • 두 값의 차이가 k보다 작으면 더 큰 값이 필요하므로 right를 이동한다.
    • 차이가 k보다 크면 작은 값을 키워야 하므로 left를 이동한다.
    • 차이가 정확히 k이면 개수를 늘리고 두 포인터를 모두 이동한다.

    모든 값이 서로 다르므로 차이가 일치한 작은 값이나 큰 값으로 같은 차이의 다른 쌍을 만들 수 없다. 두 포인터를 이동한 뒤에도 값 하나가 다른 쌍의 반대쪽 값으로 다시 사용될 수 있다. 두 포인터가 같은 원소를 가리키면 right를 한 칸 이동한다.

    완전한 Java 코드

    import java.util.Arrays;

public class Exercise06 {
    public static long countPairs(long[] values, long k) {
        long[] sorted = Arrays.copyOf(values, values.length);
        Arrays.sort(sorted);

        int left = 0;
        int right = 1;
        long count = 0;

        while (right < sorted.length) {
            if (left == right) {
                right++;
                continue;
            }

            long difference = sorted[right] - sorted[left];
            if (difference < k) {
                right++;
            } else if (difference > k) {
                left++;
            } else {
                count++;
                left++;
                right++;
            }
        }

        return count;
    }

    public static void main(String[] args) {
        System.out.println(countPairs(new long[] {24, 9, 18, 3, 15}, 6));
        System.out.println(countPairs(
                new long[] {0, 1_000_000_000_000L}, 1_000_000_000_000L));
    }
}

    07. 창고 구역 사이의 최소 이동 횟수¶

    문제¶

    제약과 함수 계약¶

    • 구역 수 n은 1 이상 200,000 이하이다.
    • 통로 수 m은 0 이상 200,000 이하이다.
    • edges는 null이 아니며, 각 원소는 두 정점 번호를 담은 길이 2의 배열이다.
    • 모든 정점 번호와 시작점 start는 1 이상 n 이하이다.
    • 중복 간선과 자기 자신으로 연결되는 간선을 허용한다.
    • 함수: public static int[] distances(int n, int[][] edges, int start)
    • 반환값은 길이가 n + 1인 배열이다. 인덱스 v에는 구역 v까지의 최소 이동 횟수를 저장한다.
    • 사용하지 않는 인덱스 0은 -1, 시작점의 거리는 0, 도달할 수 없는 구역의 거리는 -1이다.

    모든 통로의 이동 비용이 같으므로 너비 우선 탐색(BFS)을 사용한다. 시작점에서 가까운 구역부터 큐에서 꺼내며, 아직 발견하지 않은 이웃의 거리를 현재 거리 + 1로 기록한다.

    구역을 큐에 넣을 때 거리를 기록하면 방문 여부도 함께 관리할 수 있다. 같은 구역을 다시 큐에 넣지 않으므로 중복 간선이나 자기 자신으로 가는 간선이 있어도 반복 탐색하지 않는다. 정점 수가 크므로 모든 구역 쌍을 저장하는 인접 행렬 대신 인접 리스트를 사용한다.

    완전한 Java 코드

    import java.util.ArrayDeque;
import java.util.ArrayList;
import java.util.Arrays;
import java.util.List;

public class Exercise07 {
    public static int[] distances(int n, int[][] edges, int start) {
        List<List<Integer>> graph = new ArrayList<>(n + 1);
        for (int vertex = 0; vertex <= n; vertex++) {
            graph.add(new ArrayList<Integer>());
        }

        for (int[] edge : edges) {
            int from = edge[0];
            int to = edge[1];
            graph.get(from).add(to);
            graph.get(to).add(from);
        }

        int[] distance = new int[n + 1];
        Arrays.fill(distance, -1);
        ArrayDeque<Integer> queue = new ArrayDeque<>();
        distance[start] = 0;
        queue.addLast(start);

        while (!queue.isEmpty()) {
            int current = queue.removeFirst();
            for (int next : graph.get(current)) {
                if (distance[next] != -1) {
                    continue;
                }
                distance[next] = distance[current] + 1;
                queue.addLast(next);
            }
        }

        return distance;
    }

    public static void main(String[] args) {
        int[][] firstEdges = {
            {1, 2}, {1, 4}, {2, 3}, {4, 5}, {5, 3}, {6, 7}
        };
        int[][] secondEdges = {{2, 2}, {2, 3}, {2, 3}};

        System.out.println(Arrays.toString(distances(7, firstEdges, 1)));
        System.out.println(Arrays.toString(distances(4, secondEdges, 2)));
    }
}

    public class Exercise08 {
    public static long countWindows(long[] values, int width, long target) {
        if (values.length < width) {
            return 0L;
        }

        long sum = 0L;
        for (int i = 0; i < width; i++) {
            sum += values[i];
        }

        long count = sum == target ? 1L : 0L;
        for (int end = width; end < values.length; end++) {
            sum -= values[end - width];
            sum += values[end];
            if (sum == target) {
                count++;
            }
        }
        return count;
    }

    public static void main(String[] args) {
        System.out.println(countWindows(new long[] {2, -2, 2, -2, 2}, 3, 2L));
        System.out.println(countWindows(new long[] {7, -3}, 3, 4L));
    }
}

    문제¶

    1. 현재 점수가 가장 낮은 모듈 두 개를 선택한다. 두 점수를 a, b라고 할 때 a <= b다.
    2. 두 모듈을 제거하고, 점수가 a + 2 * b인 새 모듈 한 개를 넣는다.

    절차에 따라 필요한 결합 횟수를 구하라. 이미 모든 모듈이 기준을 만족하면 0, 모듈이 한 개만 남아 더 결합할 수 없는데도 기준을 만족하지 못하면 -1을 반환한다. 처음부터 모듈이 없으면 0을 반환한다.

    함수 계약과 제약¶

    public static int minimumMerges(long[] values, long threshold)
    • values는 null이 아니다.
    • 0 <= values.length <= 200_000
    • 각 원소: 0 <= values[i] <= 1_000_000_000
    • 0 <= threshold <= 1_000_000_000
    • 반환값: 기준을 만족할 때까지의 결합 횟수. 불가능하면 -1. 입력 배열을 변경하지 않는다.
    • 점수가 같다면 어느 모듈을 먼저 선택해도 된다.

    예시 1¶

    values = [2, 4, 9, 16]
threshold = 10
반환값 = 2

    첫 결합은 2 + 2 × 4 = 10이다. 남은 점수는 [9, 10, 16]이다. 다음 결합은 9 + 2 × 10 = 29이고, 남은 [16, 29]는 모두 기준을 만족한다.

    예시 2¶

    values = [0, 0]
threshold = 1
반환값 = -1

    두 모듈을 합쳐도 점수는 0이다. 모듈이 한 개만 남아 기준을 달성할 수 없다.

    접근

    매번 가장 작은 두 값을 꺼내야 하므로 최소 힙인 PriorityQueue<Long>을 사용한다. 입력값을 모두 힙에 넣고, 최솟값이 기준보다 작은 동안 두 값을 꺼내 결합한 뒤 다시 넣는다.

    최솟값이 기준 이상이면 나머지 값도 모두 기준 이상이다. 최솟값이 기준 미만인데 힙 크기가 1이라면 더 결합할 수 없으므로 실패다. 두 번째로 작은 값은 이미 기준 이상일 수도 있으며, 이때도 문제의 규칙에 따라 결합한다.

    Java 8 코드

    import java.util.PriorityQueue;

public class Exercise09 {
    public static int minimumMerges(long[] values, long threshold) {
        if (values.length == 0) {
            return 0;
        }

        PriorityQueue<Long> scores = new PriorityQueue<Long>();
        for (long value : values) {
            scores.offer(value);
        }

        int merges = 0;
        while (scores.peek() < threshold) {
            if (scores.size() < 2) {
                return -1;
            }

            long smallest = scores.poll();
            long secondSmallest = scores.poll();
            scores.offer(smallest + 2L * secondSmallest);
            merges++;
        }
        return merges;
    }

    public static void main(String[] args) {
        System.out.println(minimumMerges(new long[] {2, 4, 9, 16}, 10L));
        System.out.println(minimumMerges(new long[] {0, 0}, 1L));
    }
}

    복잡도와 경계 조건

    • 시간: O(n log n). 위 코드는 원소를 하나씩 삽입하며, 결합은 최대 n - 1번 수행한다.
    • 추가 공간: O(n).
    • 빈 배열은 0, threshold == 0이면 모든 입력값이 0 이상이므로 0이다.
    • 원소가 하나라면 그 값이 기준 이상일 때 0, 미만일 때 -1이다.
    • 점수가 같은 모듈, 점수가 0인 모듈도 처리한다. 결합마다 힙 크기가 1 줄어들므로 점수가 증가하지 않아도 반복은 끝난다.
    • 결합값은 int를 넘을 수 있으므로 long을 사용한다. 반복 중 가장 작은 값은 항상 기준 미만이다. 두 번째 값도 기준 미만이면 새 값은 3_000_000_000 미만이다. 두 번째 값이 이미 기준 이상이면 해당 결합 직후 모든 값이 기준 이상이 되어 반복이 끝난다. 이 마지막 결합의 두 번째 값은 초기값인 1_000_000_000 이하이거나 앞서 생성한 3_000_000_000 미만의 값이므로, 마지막 결합값도 7_000_000_000 미만이다. 이 제약에서는 long 범위 안에서 계산할 수 있다.
