# Web Development with LLM (웹 개발 시 LLM 활용 가이드)

웹 서비스 개발 과정에서 LLM을 효과적으로 활용하기 위한 체크리스트와 주의 사항을 정리합니다.

## 🎨 프론트엔드 개발 (Frontend)

### 1. UI/UX 디자인 및 프로토타이핑
- **컴포넌트 구조 설계**: LLM에게 디자인 시스템(Tailwind, Material UI 등)을 명시하여 일관된 코드 생성을 유도하세요.
- **이미지 및 에셋**: Placeholder 서비스나 생성형 AI를 활용한 에셋 생성을 고려하세요.

### 2. 접근성 및 반응형 대응
- **웹 접근성(WCAG)**: 생성된 마크업이 시멘틱 태그를 적절히 사용하는지, `aria-` 속성이 누락되지 않았는지 확인하세요.
- **반응형 테스트**: 다양한 화면 크기에서의 레이아웃 변화를 LLM에게 검토 요청하세요.

## ⚡ 클라이언트 사이드 로직

### 1. 상태 관리 및 데이터 패칭
- **API 통합**: API 명세서를 기반으로 타입 정의(TypeScript)와 Fetch 로직을 자동 생성하세요.
- **에러 핸들링**: 네트워크 오류나 API 응답 지연 시의 사용자 경험을 고려한 코드가 포함되었는지 확인하세요.

### 2. 보안 사항
- **XSS 방지**: LLM이 생성한 코드에서 사용자 입력을 직접 DOM에 주입(`dangerouslySetInnerHTML` 등)하는 부분이 없는지 반드시 검토하세요.
- **클라이언트 사이드 로직 노출**: 민감한 비즈니스 로직이나 API 키가 프론트엔드 코드에 포함되지 않도록 주의하세요.
