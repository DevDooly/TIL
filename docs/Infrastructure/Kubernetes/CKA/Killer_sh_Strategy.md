# 부록: Killer.sh 모의고사 활용과 시험 체크리스트

Killer.sh는 제한 시간 안에 문제를 읽고, 지정 호스트에서 작업하고, 결과를 검증하는 연습에 사용한다. Linux Foundation 계정의 시험 준비 화면에서 제공된 세션과 사용 가능 기간을 먼저 확인한다.

## 1. 세션과 문제 구성

공식 FAQ는 CKA-A와 CKA-B를 서로 다른 문제 세트로 안내한다. 같은 타입의 세션을 다시 시작하면 같은 문제를 풀게 되며, 다른 타입의 세션과는 구분해야 한다.

활성화한 실습 환경은 **연속 36시간** 사용할 수 있다. 브라우저를 닫아도 시간이 멈추지 않는다. 접근 기간 안의 환경 재시작은 실습 상태를 초기화하며, 두 번째 세션을 시작하는 것과는 다르다. 상세 조건은 [Killer.sh FAQ](https://killer.sh/faq)를 따른다.

## 2. 두 세션을 사용하는 순서

### 첫 번째 세션: 시간 관리와 취약점 확인

1. 2시간 동안 해설을 보지 않고 푼다. 실제 시험에서 허용되는 공식 자료 검색도 함께 연습한다.
2. 막히면 표시하고 넘어간다. 호스트 선택·문서 검색·명령 작성 중 어디에서 시간이 걸렸는지 기록한다.
3. 점수와 해설을 확인한다. 결과만 비교하지 말고 검증을 빠뜨렸는지도 확인한다.
4. 남은 접근 시간에 틀린 문제를 다시 푼다. 필요하면 같은 세션의 환경을 초기화한다.

### 두 번째 세션: 복습 후 다른 문제로 확인

1. 첫 세션의 오답을 정리한 뒤 활성화한다.
2. 문제를 처음 읽는 상황에서 다시 2시간을 측정한다.
3. 작업 호스트·namespace·결과 파일·실제 상태 검증을 끝까지 수행한다.

모의고사 점수를 합격 확률로 환산하지 않는다. 두 번째 세션 전에 복습 시간을 확보하고 세션 종류와 접근 시간을 대시보드에서 확인한다.

## 3. 시험 시간 배분 예시

| 구간 | 작업 |
| :--- | :--- |
| 0–5분 | 시험 안내·문제 목록·작업 호스트 확인 |
| 5–75분 | 풀이 방법이 보이는 문제부터 작업·검증 |
| 75–105분 | 표시해 둔 문제 재시도 |
| 105–120분 | 미완료 요구사항과 결과 파일·리소스 점검 |

실제 배점과 남은 시간에 따라 조정한다. 특정 세 문제가 고정 점수를 보장한다고 가정하지 않는다. 완료하면 `exit`으로 base에 돌아온 뒤 다음 문제의 SSH 호스트로 접속한다.

## 4. 응시 전 체크리스트

- [ ] 등록 이름과 일치하고 공식 요건을 충족하는 유효한 원본 신분증을 준비한다.
- [ ] 책상·주변 공간, 웹캠·마이크·조명과 네트워크를 점검한다.
- [ ] PSI Secure Browser와 공식 시스템 검사를 완료한다.
- [ ] 허용 자료·작업 호스트·복사와 붙여넣기 안내를 읽는다.
- [ ] 실습 세션과 실제 시험 예약 시간을 혼동하지 않는다.

신분증 종류와 응시 공간 조건은 [Linux Foundation 응시 지침](https://docs.linuxfoundation.org/tc-docs/certification/tips-cka-and-ckad)을 기준으로 준비한다.
